# Project Brief: L2 Medical Information System

> **Language Requirement:** All Memory Bank documentation must be written in English.
> New entries, updates, and modifications must be in English.

## Project Overview
**L2 MIS** - Comprehensive Laboratory and Medical Information System for healthcare facility management

## Core Purpose
Complete automation of medical facility operations: patient registration, referrals, laboratory and paraclinical research, consultations, inpatient treatment, and external system integrations.

## Key Functional Areas

1. **Patient Management** - Registration, medical history, personal data
2. **Referrals & Research** - Lab tests, paraclinical studies, specialist consultations, medical examinations
3. **Laboratory Services** - Biomaterial reception, testing, results validation, equipment integration (ASTM), microbiology
4. **Clinical Functions** - House calls, outpatient care, inpatient treatment, medical certificates, pharmacotherapy
5. **Administrative** - Department/hospital management, doctor schedules, staff management, cash operations, contracts
6. **Integrations** - Regional MIS (RMIS), external healthcare systems, digital signatures (ECP), HL7/SOAP/REST API, Firebase notifications
7. **Analytics & Reporting** - Statistical reports, dashboards, monitoring

## Target Users
Medical staff (doctors, nurses, lab technicians), registrars, medical facility administrators, management

## Key Requirements & Constraints
- Compliance with Russian healthcare legislation
- Patient data protection
- High availability (critical infrastructure)
- Performance with large data volumes
- Multi-tenancy support

## Success Criteria
Automation completeness, user convenience, processing speed, integration quality, system stability
